What was build

Developed a Unity prototype for a simplified Solitaire-style card game. The prototype includes:
	•	Basic drag-and-drop movement of cards between stacks.
	•	A modular Game Manager that uses the Command Pattern to execute and undo player moves.
	•	An ICommand interface for consistent move handling, allowing the system to remain extensible and clean.
	•	A simple user interface and single point of entry for the game.


 What I’d Improve With More Time

Given more time, I would:
	•	Add redo functionality, enabling players to revert undone moves.
	•	Improve the stack location to actually handle the proper solitare game logic and allow placing cards correctly based on number.
	•	Expand the prototype into a fuller Solitaire logic system with rules enforcement.
	•	Improve card animations and polish the drag-and-drop feedback for a smoother user experience.

I used ChatGPT to assist with:
	•	Getting the code to drag and drop the cards for quicker implementation.
